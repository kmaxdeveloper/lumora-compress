# Common Layer
The `common` package provides shared UI components, utility functions, and extensions that are agnostic to specific features or business logic.

## Sub-packages
- **extension**: Kotlin extension functions for common types and Android components.
- **util**: General-purpose helper classes and utility functions.
- **widget**: Custom views and reusable UI components.
- **dialog**: Base classes and implementations for system and custom dialogs.
- **bottomsheet**: Reusable bottom sheet components.
- **listener**: Shared interfaces for interaction and callbacks.
