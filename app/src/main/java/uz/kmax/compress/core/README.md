# Core Layer
The `core` package contains central infrastructure components and low-level modules that are used across the entire application.

## Sub-packages
- **di**: Dependency injection modules and configurations.
- **compressor**: Core logic for image and video compression.
- **manager**: Global managers (e.g., Theme, Language).
- **permission**: Permission handling and utility classes.
- **storage**: Local storage access and file management utilities.
- **navigation**: Application-wide navigation logic and coordinators.
- **dispatcher**: Coroutine dispatchers for managing concurrency.
