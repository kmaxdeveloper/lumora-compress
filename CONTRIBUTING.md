# Contributing Guidelines

Thank you for contributing to Lumora Compress!

## Workflow
1. Create a feature branch from `main`.
2. Follow the project's Clean Architecture and package structure.
3. Ensure your code follows the `DEVELOPMENT_RULES.md`.
4. Submit a Pull Request with a clear description of changes.

## Code Review
- All changes must be reviewed before merging.
- Focus on maintainability, performance, and adherence to architecture.
